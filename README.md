# TailSitter VTOL Aircraft

## Overview
This project focuses on the design and development of a TailSitter VTOL (Vertical Take-Off and Landing) UAV capable of performing vertical take-off, hovering, transition flight, and efficient forward cruising. The aircraft is designed to combine the hovering capability of multirotors with the aerodynamic efficiency of fixed-wing aircraft, making it suitable for surveillance, research, and autonomous aerial applications.

## Key Features
- Vertical take-off and landing without a runway  
- Smooth transition between hover and forward flight  
- Lightweight and aerodynamic airframe design  
- Stable flight control using embedded stabilization systems  
- Efficient propulsion and power management system  

## Technologies & Components
- Brushless DC motors and ESCs  
- Pixhawk 2.4.8 Flight controller with PID-based stabilization  
- Li-Po battery
- Servo motors
- Power Distribution board (PDB) and appropriate power module
- Embedded electronics and sensor integration  
- CAD modelling and aerodynamic design tools  

## Objectives
The project aims to explore VTOL aerodynamics, flight dynamics, control systems, and aircraft stability while gaining practical experience in UAV design, electronics integration, embedded systems, and real world engineering problem solving.

## Future Scope
Future improvements include autonomous navigation, AI-assisted flight control, GPS waypoint tracking, payload integration, and enhanced transition efficiency for advanced UAV applications.
